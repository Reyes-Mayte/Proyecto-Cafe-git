# Café Central
Proyecto web grupal realizado utilizando HTML, CSS, Git y GitHub. 
## Descripción
Café Central es una pequeña página web de una cafetería ficticia.
El objetivo del proyecto es aplicar conocimientos de desarrollo web
y aprender a trabajar colaborativamente utilizando Git y GitHub.
## Tecnologías utilizadas
- HTML
- CSS
- Git
- GitHub

## Funcionalidades
- Página principal
- Menú de productos
- Información sobre la cafetería
- Sección de contacto
- Diseño adaptable a diferentes tamaños de pantalla
## Proyecto escolar
Proyecto realizado para practicar control de versiones y trabajo colaborativo.
